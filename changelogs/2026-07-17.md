# Esportazione del percorso in formato GPX

## Aggiunta della funzionalità di download del tracciato GPX direttamente dall'interfaccia.

### ✨ Nuove funzionalità (Added)

* Aggiunto il pulsante **"Scarica GPX"** nella barra dei controlli per consentire l'esportazione del percorso visualizzato.
* Implementata la generazione dinamica di file **GPX 1.1** a partire dai punti del percorso corrente.
* Inclusa l'esportazione delle quote (`<ele>`) quando disponibili nei dati del tracciato.
* Il nome del file esportato viene derivato automaticamente dallo slug del percorso (con fallback al titolo della pagina).

### 🔄 Modifiche (Changed)

* Introdotte le funzioni `escapeXml()` e `buildGpxContent()` per costruire un documento GPX valido e sanificare i contenuti XML.
* Aggiunta la funzione `downloadCurrentRouteAsGpx()`, che genera il file GPX, crea un `Blob`, avvia il download e libera le risorse tramite `URL.revokeObjectURL()`.
* Salvato il nome del file sorgente in `window._gpxFileName` durante il caricamento del percorso, così da riutilizzarlo nell'esportazione.

### 🎨 Miglioramenti UI

* Definito lo stile dedicato del pulsante `.download-gpx-btn`, comprensivo di stati `hover` e `active`, coerente con il resto dell'interfaccia.

### Risultato finale

L'utente può ora scaricare in un clic il percorso attualmente visualizzato come file GPX standard, mantenendo il nome del tracciato e le informazioni di elevazione disponibili.
