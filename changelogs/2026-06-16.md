# Gestione cambio slug nelle gare esistenti

## Aggiornamento automatico dei file associati durante la modifica dello slug.

### ✨ Nuove funzionalità (Added)

- Introdotta la gestione automatica del cambio slug durante la modifica di una gara esistente.
- Aggiunta la sincronizzazione dei file GPX associati quando lo slug viene rinominato.
- Aggiornato automaticamente il campo `slug` all'interno dei file `*-gpx.json` durante la rinomina.

### 🔄 Modifiche (Changed)

- In caso di modifica dello slug, il sistema crea una nuova versione dei file GPX con il nuovo nome e rimuove quelli precedenti.
- La procedura viene eseguita sia sulle directory private che su quelle pubbliche (`GPX_DIR`, `PUBLIC_GPX_DIR`).
- I file dettaglio gara associati al vecchio slug vengono eliminati prima della successiva chiamata a `save_race()` che genera la nuova versione.

### 🐞 Correzioni (Fixed)

- Corretto il problema per cui la modifica dello slug poteva lasciare file GPX o dettagli gara con riferimenti al vecchio identificativo.
- Evitata la desincronizzazione tra nome file e valore dello slug memorizzato nel contenuto JSON.
- Implementato un fallback che effettua la semplice rinomina del file qualora l'aggiornamento del contenuto JSON non sia possibile.

### Risultato finale

La modifica dello slug di una gara aggiorna correttamente tutti i file associati, mantenendo coerenti nomi file e contenuti ed evitando residui legati al vecchio identificativo.
