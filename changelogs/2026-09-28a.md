# Anteprima locale integrata nel Race Manager

## Avvio e gestione del server di sviluppo direttamente dalla GUI.

### ✨ Nuove funzionalità (Added)

* Aggiunto il pulsante **🖥️ Anteprima** alla GUI di `RaceManagerApp`.
* Implementato `open_preview()` per avviare automaticamente `npm run dev` nella directory del progetto e aprire la preview nel browser.
* Aggiunto il rilevamento automatico dell'URL locale restituito dal server di sviluppo, compatibile con server che espongono URL `localhost` o `127.0.0.1`.
* Aggiunto il rilevamento di server già attivi sulle porte `4321`, `5173`, `3000`, `4173` e `8080`, evitando l'avvio di un secondo server.
* Aggiunto `stop_preview()` per terminare il processo di sviluppo avviato dalla GUI.

### ⚙️ Infrastruttura

* Il processo `npm run dev` viene avviato tramite `subprocess.Popen` con output intercettato e monitorato in un thread dedicato.
* Su Windows viene ricercato `npm.cmd`, mentre sugli altri sistemi viene utilizzato `npm`.
* Impostata la variabile d'ambiente `BROWSER=none` per impedire al server di sviluppo di aprire autonomamente ulteriori schede.
* Aggiunto un fallback temporizzato di 3,5 secondi per aprire l'URL predefinito `http://localhost:4321` se il server non comunica esplicitamente il proprio URL.

### 🐞 Correzioni

* Gestiti esplicitamente gli errori relativi a `npm` non installato e alla mancanza di `package.json`, mostrando messaggi diagnostici nella GUI.

### Risultato finale

Dal Race Manager è ora possibile avviare o riaprire direttamente l'anteprima web locale senza dover eseguire manualmente `npm run dev` e aprire il browser.
